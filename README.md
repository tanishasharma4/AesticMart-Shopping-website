# AesticMart

> Your Style. Your Choice. Your AesticMart.

Aesthetic, modern full-stack e-commerce starter. It includes a responsive premium storefront, cart interactions, login/register and admin dashboard views, a JSON product API, and seed data.

## Run locally

1. Install Node.js 18 or later.
2. Run `npm start`.
3. Open `http://localhost:3000`.

## API

- `GET /api/products` — seeded AesticMart catalog
- `GET /api/health` — application health status

See [docs/API.md](docs/API.md) for details.
